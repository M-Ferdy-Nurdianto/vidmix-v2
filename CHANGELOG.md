# Changelog

Semua perubahan dan pembaruan penting pada proyek Vidmix akan didokumentasikan di file ini.

## [2.0.0] - 2026-08-07
### Ditambahkan
- **UI Baru**: Antarmuka React dengan gaya desain *Neo-Brutalism* penuh animasi dan *toast notification*.
- **Shuffle Engine**: Integrasi algoritma *Fisher-Yates* untuk mengacak *playlist* lagu setiap kali melakukan render video baru.
- **Memory State**: Aplikasi kini mengingat direktori *input/output* terakhir yang digunakan.
- **Durasi Kustom**: Dukungan rendering video otomatis di-*loop* ke 15m, 30m, 1h, atau menit spesifik.
- Transisi penuh ke arsitektur *Electron + Node.js* yang sangat ringan.

## [1.0.0] - Legacy
- Versi prototipe awal.
